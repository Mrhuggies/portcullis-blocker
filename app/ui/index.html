Block list
What it does

The main layer. Before your computer visits any website it checks a file called hosts — a local address book. Portcullis writes every blocked site into it pointing at nowhere, so they can't load in any browser or app, including private windows.

It holds a public list of about 77,000 adult sites (from the open-source StevenBlack project), plus everything on your list and every bypass tool you've switched on.

It works on whole sites by name, on this computer. It can't see what's inside a site like Reddit or X, and your phone needs its own setup.

Watchdog
What it does

Keeps the block list in place. A small background job that checks the list is still there and puts it back if anything removes or edits it. It wakes the moment the hosts file changes, and once an hour anyway.It checks every five minutes and whenever the PC starts.

It runs with system rights, so quitting this panel or deleting the app doesn't stop it. It only stands aside once a removal request has waited out its 48 hours.

Chrome lock
What it does

Rules the browser has to obey. ChromeChrome and Edge can look websites up in their own way ("secure DNS"), which skips the hosts file. This switches that off, so the block list always applies.

It also blocks the 1,000 biggest adult sites inside the browser itself, as a second line if the block list were ever missing.

On a Mac this is a profile you install once, from the guide — the panel can't install it for you.

Set the first time you press Turn on. The browsers will then say they're "managed by your organization" — that's this, and it's expected.

Adding is instant. Taking one off waits 48 hours. To block an app, add the site it downloads from.

Your list

What does adding a site block?More

The site itself plus its www. and m. (mobile) addresses — so example.com blocks example.com, www.example.com and m.example.com.

Other parts of a site aren't covered automatically. If something like video.example.com still loads, add that too.

To block an app, add the website it downloads and updates from. That stops it being installed, and usually stops it working.

The adult block list (about 77,000 sites) is always included and isn't shown here.

Apps people reach for to get around a block. Switching one on blocks where it downloads and updates from. Switching one off waits, like everything else.

Tor is the exception. Once installed it routes around the block entirely — this stops it being downloaded, so if it's already on this computer, delete it as well.

How this works
What happens when I press Apply?

The panel builds your list and asks macOS for your passwordWindows for permission. A small script then checks the list contains nothing but blocks — it will refuse anything else — and writes it into your system's hosts file, which every browser and app obeys.

What does the watchdog do?

It runs in the background and puts the block back within a secondwithin five minutes if anything removes it. It's installed the first time you press Apply.

What if I delete this app?

The blocks stay. This app is only the control panel — the block list and watchdog live in the system, so deleting it removes your ability to change things, not the protection.

How do I remove it completely?

Deliberately not a button. In Terminal: sudo bash /Applications/Portcullis.app/Contents/Resources/mac/uninstall-hosts.shIn PowerShell run as administrator, from the Portcullis folder: powershell -ExecutionPolicy Bypass -File .\app\windows\uninstall.ps1, once to ask and again 48 hours later. Step by step, with pictures. It's documented because a tool that hides its own exit isn't trustworthy.

Does anything leave my computer?

No. The panel only answers this computer, there's no account, and nothing is sent anywhere.
